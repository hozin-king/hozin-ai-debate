🌍 Debat AI: Bumi Bulat vs 🗺️ Bumi Datar

Dua kubu AI berdebat dengan giliran ketat: satu kubu harus selesai penuh dulu, baru kubu lawan menjawab — tidak ada yang memotong. Episode baru digerakkan otomatis oleh GitHub Actions. Kedua kubu diperankan AI untuk hiburan dan edukasi; argumen kubu Datar adalah peran debat, bukan klaim faktual halaman ini.

Data: data/index.json + data/episodes/<id>.json di repo ini. Preview untuk aplikasi: baca data/index.json (episode terbaru, status, jumlah giliran) lalu data/episodes/<id>.json untuk giliran terakhir sebagai cuplikan.
